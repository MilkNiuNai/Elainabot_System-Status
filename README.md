# 🖥️ ElainaBot System-Status 插件

用于 ElainaBot 的 **系统状态查询插件**，支持查询bot所在服务器/电脑的 **CPU、内存、磁盘** 使用情况，并以 **美观的图片卡片** 或 **轻量的纯文本 Markdown** 两种方式输出。

---

## ✨ 功能特点

- 📊 **双模式输出**：支持 **图片卡片**（默认）和 **纯文本 Markdown** 两种输出方式，自由切换。
- 🖼️ **自适应高度**：图片模式根据磁盘数量自动调整高度，内容完整不截断。
- 🎨 **自定义背景图**：可在 `data/background.png` 放置图片作为卡片背景。
- 📦 **零配置启动**：首次运行自动生成 `data/config.yaml` 配置文件，开箱即用。
- 🔄 **刷新按钮**：两种模式均附带“刷新状态”按钮，一键重新查询。
- 🌐 **跨平台**：支持 Windows / Linux / macOS（需安装 Pillow 和 psutil）。

---

## 📦 安装与依赖

### 1. 安装插件
将本插件目录放入 ElainaBot 的 `plugins/` 文件夹中，例如：
```
plugins/系统状态/
├── main.py
├── data/
│   ├── config.yaml   (自动生成)
│   └── background.png (可选)
└── font.ttf          (可选，用于图片模式)
```

### 2. 安装 Python 依赖
```bash
pip install psutil Pillow aiohttp
```

> **注意**：如果只使用文本模式，可以只安装 `psutil`，Pillow 和 aiohttp 可省略（但建议完整安装以备切换）。

## ⚙️ 配置文件

配置文件位于 `data/config.yaml`，首次运行自动生成，内容如下：

```yaml
# 系统状态插件配置文件
# ========================================
# 1. base_url: 你的 ElainaBot 公网访问地址（含端口）
#    示例: http://103.39.66.30:45200
# ========================================
base_url: "http://127.0.0.1:5200"   # 默认本地地址，请务必修改

# ========================================
# 2. use_image: 是否使用图片输出
#    - true  : 生成美观的图片卡片（默认）
#    - false : 使用纯文本 Markdown 输出（轻量，无需生成图片）
# ========================================
use_image: true

# ========================================
# 3. use_background: 是否使用自定义背景图
#    - true  : 使用 data/background.png 作为背景（若文件存在）
#    - false : 不使用背景图，纯色背景
# ========================================
use_background: false
```

### 配置项说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `base_url` | string | `http://127.0.0.1:5200` | **必填**，ElainaBot 的公网访问地址（含端口），用于图片加载。 |
| `use_image` | boolean | `true` | `true`=图片模式，`false`=文本模式。 |
| `use_background` | boolean | `false` | `true`=启用自定义背景图（需 `data/background.png` 存在）。 |

## 🚀 使用方法

在群聊或私聊中发送以下命令：

```
/系统状态
或
系统状态
```

机器人将根据 `config.yaml` 中的 `use_image` 配置返回对应格式的结果。

### 图片模式示例

- 发送命令后，返回一张包含系统信息的卡片图片，附带 **“刷新状态”** 按钮。
- 卡片内容：操作系统、查询时间、CPU 占用（进度条）、内存占用（进度条）、磁盘列表（含进度条）。
- 图片高度根据磁盘数量自动调整，清晰易读。

### 文本模式示例

- 返回 Markdown 格式的文本，包含相同的系统信息，同样带有 **“刷新状态”** 按钮。
- 适合低带宽、纯文本环境，无需加载图片。

## 🎨 自定义背景图

如果你希望在图片模式下使用自定义背景，请：
1. 将 `use_background` 设为 `true`。
2. 将你的背景图片命名为 `background.png`，放入 `data/` 目录。
3. 图片会自动适配卡片尺寸（居中裁剪或拉伸）。

> **推荐尺寸**：宽度 ≥ 600px，高度 ≥ 500px，以便完整显示内容。

## 🔧 常见问题

### 1. 图片无法显示？
- 检查 `base_url` 是否配置为 ElainaBot 可公网访问的地址（含端口）。
- 确保 `data/status.png` 已生成，并可通过 `http://你的IP:端口/api/ext/status/status.png` 访问。
- 检查 ElainaBot 的 Web 服务是否正常运行（`server.port` 配置正确）。

### 2. 中文字体显示为方框？
- 在插件目录下放置一个中文字体文件（如 `font.ttf` 或 `msyh.ttf`），插件会自动加载。
- 或修改 `find_font()` 函数中的字体路径为系统已存在的字体。

### 3. 如何切换图片/文本模式？
- 修改 `data/config.yaml` 中的 `use_image` 字段，然后**重载插件**或**重启机器人**即可生效。

### 4. 背景图不生效？
- 确认 `use_background` 为 `true`，且 `data/background.png` 文件存在。
- 检查图片格式是否为 PNG，并确保文件可读。
